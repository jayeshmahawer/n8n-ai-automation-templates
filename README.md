## 🚀 How to Use

1. Open your **n8n instance** (self-hosted or cloud)
2. Go to **Workflows → Import from File**
3. Select the `.json` file from the relevant category folder
4. Configure your credentials (API keys for OpenAI, Google, Apify, etc. — see each workflow's node settings)
5. Activate and run 🎉

> **Note:** Most workflows require API keys for services like OpenAI, Google Sheets, Apify, Serper/SerpApi, or HubSpot. Check each JSON's node configuration before running.
